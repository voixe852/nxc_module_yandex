# nxc_module_yandex
Working script for the yandex module for nxc
Ty for https://github.com/Moghees244

#Installation

1. NXC should be updated to version 1.4.0.
2. If you have nxc installed via pipx, then put the module on the path `~/.local/pipx/venvs/netexec/lib/python3.11/site-packages/nxc/modules/`
3. Check `nxc smb 192.168.0.1 -u '' -p '' -M yandex`
